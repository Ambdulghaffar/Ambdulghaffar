### 📌 Featured Projects

- 🔹 **[StockFlow — Fullstack Inventory Management](https://github.com/Ambdulghaffar/stockflow-web)** ([backend](https://github.com/Ambdulghaffar/stockflow-api)) — Complete e-commerce & inventory platform: Next.js 15 (App Router, Server Components/Actions) + Spring Boot. Role-based dashboard (Admin/Manager/Client), JWT + Google OAuth authentication, RBAC middleware, Redux Toolkit shopping cart, order management with automatic stock tracking, sales/stock reports with data visualization, signed Cloudinary image uploads.
- 🔹 **[CV Analyzer AI](https://github.com/Ambdulghaffar/cv-analyzer-infra)** — Dockerized fullstack platform (Next.js + FastAPI) using an LLM to score resume/job compatibility, with candidate ranking and cover letter generation.
- 🔹 **[Fraud Investigation Chatbot](https://github.com/Ambdulghaffar/ccfd-investigation-chatbot)** — Hybrid fraud-detection system combining a classic ML risk-scoring baseline (imbalanced-data stratification, Scikit-learn) with an LLM investigation agent (Llama 3 via Groq API). Features prompt/context engineering, simulated RAG memory, anti-jailbreak safeguards, and automated Bot-vs-Bot evaluation (confusion matrix, F1-score, ROC/PR-AUC). Deployed as an interactive Streamlit dashboard.
